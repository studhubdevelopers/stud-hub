# StudHub — платформа студенческого краудфандинга

Статический сайт (HTML/CSS/JS без сборки) + Supabase в качестве бэкенда.

- Запуск локально: `python3 -m http.server 8000` и открыть http://localhost:8000
- Пока `js/config.js` пуст — работает демо-режим (данные хранятся в браузере).
- Подключение Supabase: см. `supabase/README.md`.
- После правки файлов поднимайте `VERSION` в `sw.js`, чтобы браузеры забрали свежие файлы.
